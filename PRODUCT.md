# OnlyTweakWindows

## Platform and stack

Portable Windows desktop utility: C# / .NET 10, Windows Forms, Italian UI, self-contained win-x64 executable. Windows 10 build 17763+ and Windows 11 on native x64; technical compatibility is distinct from OS servicing and tested qualification.

## Users and purpose

Private PC users who want understandable Windows personalization, gaming configuration, diagnostics and local maintenance. There is no customer, domain or remote administration client workspace.

## Product principles

- Preserve the established native dark UI and keyboard navigation.
- Explain the setting, current state, privileges and consequences before applying a change.
- Apply verifiable local changes with audit and persistent recovery; keep guided Windows settings visibly incomplete.
- Preserve security features, user data, existing backups and unrelated configuration.
- Report observed results and qualification limits; make no guaranteed FPS claims.

## Capabilities and constraints

Desktop/Explorer tweaks, temporary keep-awake, three cumulative gaming guidance levels, local network diagnostics, maintenance, printing and advanced local WinRM enablement. The main UI runs without mandatory elevation; privileged work uses a local worker with a closed catalog. No free shell, downloaded scripts, automatic debloat, cloud clipboard activation or security-feature disabling.

## Evidence

Tests distinguish synthetic backends and UI renders from read-only host checks and VM qualification. Administrative tweaks are never tested against the development host. Product documentation records actual validation results.
